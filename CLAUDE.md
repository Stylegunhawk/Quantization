# Repo Instructions

## Git commits
- Rule 1 (absolute): never run `git commit` in this repo. The user commits manually.
- Rule 2: if the user explicitly asks you to commit anyway, follow this format —
  - Commit message is a single line only (no multi-line or bulleted body).
  - Do not append any trailers: no `Co-Authored-By`, no `Claude-Session`, nothing.
