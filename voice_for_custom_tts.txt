I have been working on speech models for the last few weeks, mostly on my own laptop. The setup is fairly simple. Only one model stays in memory at a time, and I measure how long each one takes before I trust any of the numbers. Most of the interesting problems turn out to be about memory rather than raw speed. When something looks wrong, I read the log first, and I check the measurement itself before I change a single line of code. That habit has saved me a lot of time.
